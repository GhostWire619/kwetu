# tests/

Golden fixtures (ephemeris, determinism) and Playwright browser tests —
MASTER_PROMPT.md §42, ROADMAP.md §5 S0.11, ADR-011. `*.test.ts` files here
run under `npm test` in the node environment.

Layout (S0.11):

- `determinism/` — bitwise state-hash regression for the Rapier contact-bubble
  sim (`npx vitest run tests/determinism`). Hashes are sha256 over raw IEEE-754
  f64 bit patterns — never formatted floats (ADR-011 Decision 2).
- `golden/ephemeris/` — committed ephemeris fixtures (schema
  `kwetu.golden.ephemeris/1`) generated by `python tools/oracle/generate_golden.py`
  from skyfield + `de440s.bsp` (kernel cached in gitignored `.bake/ephemeris/`,
  never committed; the fixture carries its sha256). Verified against
  astronomy-engine by `tools/spikes/s0.11/golden-verify.test.ts`.
- `e2e/` — Playwright browser smokes: `npx playwright test` (config
  `playwright.config.ts` at the repo root). Specs are named `*.pw.ts` — NOT
  `*.spec.ts` — because vitest's default include globs `**/*.{test,spec}.ts`
  and would fail collecting them (ADR-011 §Evidence D). `fixtures/` holds the
  pages the specs drive; the three.js fixture is served by the vite dev server
  the config starts on port 5199.
