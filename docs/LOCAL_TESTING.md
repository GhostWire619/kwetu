# Early local testing

Status: playable local prototype, verified 2026-09-06.

## Entry points

- Surface test: `http://127.0.0.1:5199/client/index.html?mode=surface` on the existing root-serving Vite instance.
- Space camera: `http://127.0.0.1:5199/client/index.html?mode=space`.
- Region-loading diagnostic: `http://127.0.0.1:5199/client/index.html?region=stone-town`.

With locked dependencies installed (`npm ci`), run `npm run dev -- --host 127.0.0.1 --port 5199` from the repository root. This command serves the client directory, so its surface URL is `http://127.0.0.1:5199/?mode=surface`. Do not start another process on an occupied port.

Surface mode requires `.bake/meshes/stone-town.terrain.glb` and its manifest. Both exist on the development machine. They are regenerated by `npm run bake:terrain` once source DEM files are available; cached data are not included in Git. The production build (`npm run build`) needs these data served separately at `/data/region/`.

## Scope

This is a local single-player prototype. Terrain comes from the existing Stone Town Copernicus bake; test props are original placeholders, not reconstructed city buildings. Local saves are prototype conveniences, not authoritative multiplayer persistence. Space view is a separate test mode, not a seamless rocket trip. The full planet LOD comparison and integrated-GPU performance gate remain open.

Surface testing needs no account or Docker service. The separate backend stack is documented in [infra/README-dev.md](../infra/README-dev.md); it is not yet connected to this local surface prototype.

Report browser, mode, action, expected behavior, actual behavior, and whether reset/reload recovers. Check walking, steering, entering/exiting the car, slopes, camera, reset, blur/focus, reload, and Swahili/English controls. A screenshot alone cannot verify physics.

## Controls

- Walk: `W A S D`; jump: `Space`.
- Enter or leave the nearby car: `E`.
- Drive: `W A S D`; brake: `Space`.
- Camera: arrow keys or mouse drag.
- Reset the current test: `R`.
- Use the `EN`/`SW` button for English or Swahili help text. Swahili is the default.

## Verification recorded on 2026-09-06

- TypeScript: `npm run typecheck` passed.
- Unit and integration tests: 30 files, 461 tests passed.
- Browser tests: 10/10 passed with one worker across Chromium and Firefox. The suite exercises the space shell, streamed Stone Town region, walking, entering the car, driving, leaving the car, reset, Three.js rendering and WebGL2 pixel readback.
- Production build: passed. The space shell is 685.39 kB raw / 185.63 kB gzip. Surface mode is loaded separately and is 2,922.77 kB raw / 1,117.78 kB gzip, largely because it includes the Rapier physics runtime. The terrain file is served separately.
- License ledger: passed with zero violations and three existing deferred warnings.

The surface scene has real baked terrain and a matching collision mesh, plus an original test car and simple test props. It does not yet contain reconstructed Stone Town buildings, rockets, spacecraft, seamless surface-to-orbit travel, multiplayer, or authoritative save restoration. Automated browser results do not establish frame-rate performance on the target integrated-graphics laptop; that hardware measurement remains open.
