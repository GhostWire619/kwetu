# ATTRIBUTIONS.md — exact attribution strings (CI-checked)

> **CI rule:** any new row added to [THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md)
> **without an attribution string fails the build.**

This file is the single source of truth for attribution **strings**.
THIRD_PARTY_ASSETS.md decides **which** rows need one; this file fixes **what
the string says**. CI compares the strings below against the built
credits-screen and map-footer resources under one standard: each string is
trimmed and runs of whitespace collapse to a single space — **any other
difference fails the build**. Editing a string here without rebuilding the UI —
or vice versa — fails the build.

## Rule: legal strings are never translated

Legal strings stay **verbatim in English in every UI language**, including
Swahili — standard practice, since license attribution is a legal notice and a
translated notice is not the notice the licensor requires. Only the *screen
labels around* the strings are translated (§Screen labels).

## Legal strings

<a id="osm"></a>

### STR-OSM — OpenStreetMap

- String (verbatim): `© OpenStreetMap contributors, under the Open Database License (ODbL) 1.0`
- Links: `© OpenStreetMap contributors` links to
  https://www.openstreetmap.org/copyright [EXTERNAL]; the ODbL link text is
  `Open Database License (ODbL) 1.0`, linking to
  https://opendatacommons.org/licenses/odbl/1-0/ [EXTERNAL].
- Used in: credits screen, map footer, docs footer, `data/` distributions.

<a id="geofabrik"></a>

### STR-GEOFABRIK — Geofabrik

- String (verbatim): `Data processed by Geofabrik GmbH`
- Link: https://www.geofabrik.de [EXTERNAL]. Rendered directly below STR-OSM
  wherever OSM extracts processed by Geofabrik are used.

<a id="copernicus-dem"></a>

### STR-COPERNICUS — Copernicus

- String (verbatim): `Contains modified Copernicus data [year]`
- `[year]` is substituted at build time with the publication year of the
  products actually used (e.g. `Contains modified Copernicus data 2026`);
  an un-substituted `[year]` rendering is a build error.
- Copernicus data terms have no SPDX identifier — this string is the required
  credit. Licence-page link target: [PLACEHOLDER — confirm exact URL at first
  data build].

<a id="nasa"></a>

### STR-NASA — NASA / USGS data acknowledgment

- String (verbatim): `Terrain and imagery data courtesy of NASA and the U.S. Geological Survey.`
  `Kwetu is not affiliated with, endorsed by, or sponsored by NASA or the U.S. Geological Survey.`
- The second sentence is part of the string, not boilerplate: NASA/USGS data
  is used with acknowledgment only — **no endorsement implication**
  (see §Forbidden).

<a id="natural-earth"></a>

### STR-NE — Natural Earth

- String (verbatim): `Made with Natural Earth.`
- Link: https://www.naturalearthdata.com [EXTERNAL]. Courtesy credit for
  public-domain Natural Earth data (produced by NACIS) — upstream requests it
  voluntarily; it is **not** a license debt. (Upstream's long form,
  `Made with Natural Earth. Free vector and raster map data @
  naturalearthdata.com.`, is the alternative.) Used in: far-field imagery
  contexts (DATA_SOURCES.md); the string enters the CI-generated table when
  the Natural Earth dataset row lands.

<a id="openmaptiles"></a>

### STR-OMT — OpenMapTiles (vector-tile schema credit)

- String (verbatim): `© OpenMapTiles`
- Link: https://github.com/openmaptiles/openmaptiles [EXTERNAL]. Required by
  the OpenMapTiles schema license (CC-BY) whenever tiles generated with the
  OpenMapTiles profile (planetiler default) are rendered — the credit must be
  visible to users, joined with STR-OSM (the tile DATA is ODbl OSM; the tile
  SCHEMA carries this credit). First used by the 2026-09-06 basemap bake
  (`tools/bake/basemap.ps1` → per-region PMTiles).
- Used in: map footer (whenever OMT-profile tiles render), credits screen.

## Map footer

Compact form; same legal strings, both languages:

- **EN:** `Map data: © OpenStreetMap contributors, under the Open Database License (ODbL) 1.0 · Contains modified Copernicus data [year]`
- **SW:** `Data ya ramani: © OpenStreetMap contributors, under the Open Database License (ODbL) 1.0 · Contains modified Copernicus data [year]`

The footer carries OSM + Copernicus only; the full NASA/USGS acknowledgment
and Geofabrik credit live in the credits screen (kept out of the footer for
size, but present wherever terrain/imagery is discussed in docs). When
vector tiles generated with the OpenMapTiles profile are rendered, the
footer joins STR-OMT with STR-OSM:
`© OpenMapTiles © OpenStreetMap contributors` (link targets per the two
string entries above) — the OMT credit is a visible-credit obligation of
the tile schema, not a footer-size decoration.

## Docs and repo attribution

- **`README.md`** carries a short "Data and assets" section with STR-OSM,
  STR-COPERNICUS and STR-NASA verbatim, plus links to this triad.
- **`NOTICE`** (repo root) points at this triad and states the `data/` ODbL
  split (already in place).
- **Docs pages** carry a one-line footer joining STR-OSM, STR-COPERNICUS and
  STR-NASA with `·`.
- **Published `data/` artifacts** ship their DATA_SOURCES.md provenance row
  and the ODbL 1.0 text (LICENSES.md §Data layers).

## Forbidden

- **NASA insignia rendering.** The NASA insignia, the "worm" logotype, and
  program/mission logos are protected by US law (14 CFR Part 1221)
  **regardless of any asset's stated license status**. Never render them
  in-game, in docs, in UI iconography, or in promotion.
- **Endorsement implications.** Never phrase, design, or juxtapose anything
  implying that NASA, the USGS, ESA, the OpenStreetMap Foundation, Geofabrik,
  or any data provider endorses, operates, or participates in Kwetu.
  STR-NASA's non-endorsement sentence stays intact wherever the string
  appears.
- **"according to NASA" on AI-generated content.** Never caption or cite
  AI-generated content (e.g. TRELLIS-generated meshes) as NASA data or
  "according to NASA". AI-generated surfaces are Kwetu's own content, and
  must be traceable to their generation row in THIRD_PARTY_ASSETS.md.
